# Calibrated Preference Learning

Code and experiments for studying the **calibration of probabilistic ranking
models**. Given features `X`, a ranking model predicts a full distribution over
rankings of a fixed set of items. We ask: *are those predicted ranking
probabilities calibrated?* — and we measure it with rank-wise / full-rank
**sub-k** and **top-k** Expected Calibration Error (ECE).

The repository contains everything needed to reproduce every figure:
the calibration metrics, five ranking models, twelve real label-ranking
datasets plus synthetic generators, and a separate RLHF reward-model study on
RewardBench-2.

## What this measures

For each dataset we train five ranking models with 5-fold cross-validation,
temperature-calibrate the neural preference model on a held-out split, and then
evaluate, per fold:

- **Kendall's τ** — ranking accuracy of the predicted mode.
- **Sub-k / Top-k ECE** — calibration of the predicted ranking distribution,
  in both a *rank-wise* and a *full-rank* variant, swept over every `k` from
  `2..n_items` (sub-k) and `1..n_items-1` (top-k). Configurable rank weighting,
  discrepancy measure, and bin spacing.

Results are written to `results/<dataset>/` as CSVs plus publication-ready
plots.

## Installation

The project targets **Python 3.11** and is managed with
[`uv`](https://docs.astral.sh/uv/). The lockfile (`uv.lock`) pins exact
versions for byte-for-byte reproducibility.

```bash
# from the repository root
uv sync
```

This creates `.venv/` and installs all dependencies, including the **vendored
`scikit-lr` fork** (`[tool.uv.sources]` points at `./scikit-lr`), which provides
the RPC pairwise label rankers used by the `RPC` / `PlackettLuceRPC` baselines.

> **Note on `scikit-lr`.** It contains Cython extensions. A prebuilt binary for
> macOS arm64 / CPython 3.11 is committed (`*.cpython-311-darwin.so`). On any
> other OS, Python version, or architecture, `uv sync` rebuilds it from source
> (a C/C++ toolchain is required; `cython` is already in the dependency set).

All commands below assume the `uv` environment. Prefix any script with
`uv run`, or activate the venv (`source .venv/bin/activate`) and drop the
prefix.

> **Run scripts from the repository root.** Data and result paths are relative
> (e.g. `src/cal_pref/data/...`, `results/...`); running from another directory
> will fail to find inputs.

## Quickstart

Smallest end-to-end run (a tiny synthetic Plackett-Luce dataset, ~1 minute):

```bash
uv run python experiment_calibration.py --dataset synthetic_pl_probs
```

This writes ECE/τ CSVs and plots to `results/synthetic_pl_probs/`.

Run the test suite to verify the metrics are behaving:

```bash
uv run pytest tests/ -q
```

## Reproducing the results

The pipeline has three stages: **(1)** run the experiment to produce per-dataset
CSVs, **(2)** render figures from those CSVs, **(3)** auxiliary analyses.

### 1. Label-ranking calibration (main experiment)

```bash
uv run python experiment_calibration.py \
    --dataset       <dataset_name> \
    --rank_weighting <uniform|prevalence|pred_mass|most_confident|95_prob_mass|top_10> \
    --discrepancy    <abs|jeff|log_ratio|rel_p|rel_q|kl> \
    --bin_spacing    <linear|log>
```

| Flag | Default | Meaning |
|---|---|---|
| `--dataset` | `synthetic_pl_probs` | Real dataset name or a `synthetic_*` generator (see [Datasets](#datasets)). |
| `--rank_weighting` | `uniform` | How per-ranking ECE terms are aggregated. |
| `--discrepancy` | `abs` | Calibration discrepancy measure (`abs` and `jeff` are the ones used in the paper figures). |
| `--bin_spacing` | `linear` | Confidence-bin spacing for ECE. |

Fixed configuration (hard-coded in `experiment_calibration.py.__main__`, listed
here for transparency): seeds `42` everywhere, `5`-fold CV with an internal
80/20 train/calibration split, `50` epochs, batch size `64`, Adam `lr=1e-3`,
synthetic runs use `10_000` samples / `2` features / `3` items. For datasets
with very large ranking spaces (`movies`, `letter`, `libras`, `vowel`,
`pendigit`, `yeast`) ECE is restricted to the rankings observed in the test
fold; otherwise all permutations are enumerated.

**Reproduce every dataset** (the main result table):

```bash
for ds in authorship glass iris letter libras movies pendigits \
          segment vehicle vowel wine yeast political; do
  uv run python experiment_calibration.py --dataset "$ds"
done
```

To reproduce the **abs-vs-jeff comparison figures**, each dataset must be run
under both discrepancies (and the rank weightings used by the figure scripts —
`abs` with `95_prob_mass`, `jeff` with `uniform`):

```bash
uv run python experiment_calibration.py --dataset political --discrepancy abs  --rank_weighting 95_prob_mass
uv run python experiment_calibration.py --dataset political --discrepancy jeff --rank_weighting uniform
```

### 2. Figures

Both figure scripts read the CSVs produced in step 1 and are configured via the
`__main__` block at the bottom of the file (dataset, `k` values, weighting,
discrepancy, bin spacing). **Edit those constants to target a different
dataset/config**, then run:

```bash
uv run python visualise_ece.py             # grouped box-plots + ECE-vs-k error bars
uv run python visualise_ece_comparison.py  # abs vs. jeff side-by-side comparison
```

Figures are written to `results/improved_plots/`. The `proportion` term that
appears in CSV filenames is looked up in the `dataset_to_proportion` dict inside
each script (`{political: 1.0, movies: 0.0}`); add an entry there for any other
dataset you want to plot.

### 3. Dataset statistics

Print observed vs. theoretically-possible rankings for every dataset (Table:
ranking-space coverage):

```bash
uv run python number_of_rankings.py
```

### 4. RLHF / RewardBench-2 study

Computes binary ECE and mean absolute logit difference for the top
Bradley-Terry reward models on the
[RewardBench-2](https://huggingface.co/spaces/allenai/reward-bench) leaderboard.

```bash
uv run python analyze_rb_logit_diff.py \
    --leaderboard current-rbv2-data.csv \
    --top-n 10 \
    --k 10
```

A leaderboard snapshot (`current-rbv2-data.csv`) is committed; refresh it via
the "Download CSV" button on the RewardBench space. Outputs (correlation bar
chart, raw ECE score plots) go to `rlhf_ece/`.

> **Requires network access** — the script streams each model's per-example
> scores from the HuggingFace Hub (`allenai/reward-bench-2-results`) into
> `--cache-dir` (default `cache_reward_bench/`). It also expects a
> `label_ranking_datasets.json` file in the repo root, which is **not vendored**;
> see [Known caveats](#known-caveats).

## Datasets

**Real label-ranking datasets** (vendored under `src/cal_pref/data/`, no
download needed): `authorship`, `glass`, `iris`, `letter`, `libras`, `movies`,
`pendigits`, `segment`, `vehicle`, `vowel`, `wine`, `yeast`, `political`.

**Synthetic generators** (pass as `--dataset`): `synthetic_pl_probs`
(Plackett-Luce with weights `[3,2,1]`), `synthetic_mallows_probs`,
`synthetic_skewed_probs`, `synthetic_equal_probs`, `synthetic_random_probs`.
Each produces 3 items so the full permutation space is enumerable and the true
ranking distribution is known exactly — useful for sanity-checking calibration.

## Models

| Name in code / CSV | Abbrev. | Description |
|---|---|---|
| `PlackettLuce` | PL | Neural Plackett-Luce model (utility per item → PL likelihood). |
| `MallowsModel` | MM | Mallows model fit from data (Kendall distance, ML reference + dispersion). |
| `PreferenceModel` | RC | Neural classifier over the unique observed rankings, **temperature-scaled** on the calibration split. |
| `PlackettLuceRPC` | PL-RPC | Calibrated pairwise ranker (decision tree + sigmoid calibration) → Bradley-Terry matrix → Plackett-Luce weights via iterative conversion. |
| `RPC` | RPC | The raw calibrated pairwise (Ranking-by-Pairwise-Comparison) baseline, scored on its pairwise marginals. |

## Output files

Per `experiment_calibration.py` run, in `results/<dataset>/`:

- `subk_ece_results_<dataset>_<prop>_<weight>_<disc>_<spacing>.csv`
- `topk_ece_results_…csv`
- `subk_full_rank_ece_results_…csv`, `topk_full_rank_ece_results_…csv`
- `kendalls_tau_results_<dataset>.csv`
- ECE-vs-k plots (`.png`/`.pdf`)

Figure scripts add grouped/comparison plots under `results/improved_plots/`.
The RLHF study writes to `rlhf_ece/`.

`<prop>` is the proportion of the permutation space considered for ECE, rounded
to 2 decimals — it is part of the filename, so figure scripts must know it
(via their `dataset_to_proportion` dict).

## Ranking representations (developer reference)

The code uses two equivalent encodings of a ranking, each in a fixed place.

**1) Ranks-per-item** — datasets, training labels, `.predict()`
- Shape `(n_samples, n_items)`; `y[s, j]` is the rank (1 = best) of item `j+1`.
- Example (3 items): `y = [2, 3, 1]` ⟹ item 3 best, then item 1, then item 2.
- Everything from `cal_pref.utils.load_lr_data` / `synthetic_data` and every
  model's `.predict(...)` is in this format.

**2) Orderings / permutations** — predicted distributions
- Tuples like `(2, 1, 3)` meaning the best→worst order of **item IDs**
  (`2 > 1 > 3`).
- Every `predict_ranking_distribution(...)` returns a dict
  `{ ordering_tuple: probability_per_sample }`. Keys may be full rankings
  (length `n_items`) or partial orderings (e.g. `(2, 1)` ⟹ `2 > 1`).

**Rule of thumb:** from the dataset or `.predict()` → ranks-per-item; a key in
`y_pred_proba` / `distribution` → an ordering.

## Known caveats

- **Figure scripts are config-by-editing.** `visualise_ece.py` and
  `visualise_ece_comparison.py` take no CLI args; change the constants in their
  `__main__` block (and add the dataset to `dataset_to_proportion`) to target a
  different dataset/weighting/discrepancy.
- **`analyze_rb_logit_diff.py` needs `label_ranking_datasets.json`** in the repo
  root; it is not vendored. The active code path computes overall metrics, but
  the file is opened at startup, so provide it (even as `{}`) or comment out
  that load before running. The script also requires HuggingFace network access.
- **Vendored `scikit-lr` binary is macOS arm64 / CPy3.11 only.** Other
  platforms rebuild from source during `uv sync` (needs a C/C++ toolchain).
- **Long runs.** Large-ranking-space datasets (`letter`, `pendigits`, `movies`,
  …) are the slow ones; ECE there is intentionally restricted to test-fold
  rankings to keep it tractable.
- Determinism: all RNGs are seeded to `42`. Results are reproducible on the same
  platform/library versions (pinned in `uv.lock`); minor numerical drift across
  BLAS/torch builds is expected.
